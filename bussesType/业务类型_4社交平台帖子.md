#### 2.2 社交平台帖子（微博、知乎、小红书）

**数据特征**：半结构化，10000-1000000 条，文本多样、广告多

**业务字段清单**：post_id, user_id, post_content, like_count, repost_count, comment_count, post_time, topic_tag

**业务核心字段**：post_id(主键), post_content, post_time, like_count, repost_count

##### 字段详细说明表

| 英文字段名      | 中文名   | 来源性质 | 处理方式                                               | 说明                       |
| --------------- | -------- | -------- | ------------------------------------------------------ | -------------------------- |
| post_id         | 帖子 ID  | 原始     | 保留纯字母数字，按平台规范化                    | 帖子唯一标识           |
| user_id         | 用户 ID  | 原始     | 保留纯数字，缺失填充"anonymous"                       | 用户唯一标识               |
| post_content    | 帖子内容 | 处理后   | 去 HTML 标签、emoji、@用户、#话题、链接、限制 ≤10000 字 | 核心内容，需详细清洗       |
| like_count      | 点赞数   | 处理后   | 去非数字，换算单位("5 万"→50000)，转整数             | 互动自然，需检测异常      |
| repost_count    | 转发数   | 处理后   | 去非数字，转整数，检测异常                      | 互动计数，需检测异常    |
| comment_count   | 评论数   | 处理后   | 去非数字，转整数                                               | 评论计数              |
| post_time       | 帖子时间 | 处理后   | 相对 → 绝对时间，统一 YYYY-MM-DD HH:MM:SS             | 帖子发布时间               |
| topic_tag       | 主题标签 | 处理后   | 分解为数组、去重、规范化、≤15 个       | 文章标签              |
| is_repost       | 是否转载 | 新增     | 转载标记(0/1)                                          | 区分原创和转载         |
| is_spam         | 是否垃圾 | 新增     | 垃圾评论标记(0/1)                                      | 启用基于内容的检测         |
| clean_time      | 清洗时间 | 新增     | 清洗完成时间                                           | 应用 timestamp             |

**常见问题与清洗方案**:

##### 分步骤清洗流程

**第一阶段：去重与帖子有效性验证**

| 问题类型     | 具体表现             | 清洗方案                                                          | 执行步骤                                                         | 无法清洗处理                                   |
| ------------ | -------------------- | ----------------------------------------------------------------- | ---------------------------------------------------------------- | ---------------------------------------------- |
| 重复帖子     | 同一内容多个用户发布 | 按 post_id 去重或按内容相似度检测重复内容                       | 1. 按 post_id 分组 2. 检测相似度 3. 保留原始帖子 4. 标记是否转发 | 相似度 70-90% 之间 → 标记"repost_suspicious"   |
| post_id 缺失 | 帖子无唯一标识       | **补充策略**：由(user_id, post_content, post_time)组合生成哈希 ID | 1. 生成哈希值 2. 检验唯一性 3. 标记"id_generated"                | 组合字段也缺失 → 标记"critical_missing" → 删除 |
| user_id 缺失 | 帖子作者未知         | **补充策略**：填充"anonymous_user"                                | 1. 检查是否有其他来源 2. 填充临时用户 ID                         | 保留为"unknown"                                |

**第二阶段：文本清洗与补充**

| 问题类型 | 具体表现                 | 清洗方案                        | 执行步骤                                                 | 准确性评估        | 无法清洗处理                          |
| -------- | ------------------------ | ------------------------------- | -------------------------------------------------------- | ----------------- | ------------------------------------- |
| 转载重复 | 同一内容转发             | 按标题/内容相似度>90% 检测      | 1. 计算文本相似度 2. 保留原创、标记转载              | 相似度>90% 为转载 | 无法检测 → 标记"similarity_unknown"   |
| 文本污染 | HTML、表情、@、话题      | 去 HTML → 去表情 → 去@ → 去话题 | 1. BeautifulSoup 去 HTML 2. 正则去 emoji 3. 根据平台规则 | 清洗后>0 且可读   | 全是污染 → 标记"content_invalid"      |
| 广告内容 | 推广链接、商品推荐、微商 | 识别广告特征词，检测比例>30%    | 1. 计算推广链接比例 2. 检测商业特征词 3. 标记 marketing  | 推广比例>30%      | 无法确定 → 标记"marketing_suspicious" |

**第三阶段：异常值检测与修正**

| 问题类型   | 具体表现             | 清洗方案                         | 执行步骤                             | 异常判定标准          | 无法清洗处理                         |
| ---------- | -------------------- | -------------------------------- | ------------------------------------ | --------------------- | ------------------------------------ |
| 互动数异常 | 赞数超百万、转发异常     | 范围检验(≥0, <1000000)，模式检测 | 1. 检查范围 2. 检查转发/赞绑定关系 | 标准范围 0-1000000    | 无法修正 → 标记"engagement_abnormal" |
| 时间异常   | 时间辅范围或形式不一 | 时间范围检验，统一格式           | 1. 检查范围 2. 格式转换 3. 标记异常  | post_time <= 当前时间 | 时间无法修正 → 标记"time_invalid"    |

**第四阶段：文本清洗与编码处理**

| 问题类型 | 具体表现          | 清洗方案                | 执行步骤                                       | 验证方式             | 无法清洗处理                        |
| -------- | ----------------- | ----------------------- | ---------------------------------------------- | -------------------- | ----------------------------------- |
| 超长文本 | 超过 10000 字     | 截断至 10000 字         | 1. 检测长度 2. 截断 3. 标记"content_truncated" | 截断是否损失关键信息 | 手工评估是否保留                    |
| 文本乱码 | 帖子标题/内容乱码 | chardet 检测 → 重新解码 | 1. chardet 检测 2. 重新解码 3. 验证            | 解码后可读           | 编码无法识别 → 标记"encoding_error" |

##### 缺失值补充策略汇总

| 缺失字段       | 一级补充(>95%) | 二级补充(70-95%)            | 外部补充(<70%)      | 补充失败处理                |
| -------------- | -------------- | --------------------------- | ------------------- | --------------------------- |
| **post_id**    | 源系统 ID      | 生成(user_id + content)哈希 | 序列号              | **无法补充** → 删除         |
| **user_id**    | 源系统 user_id | 其他来源推断                | 填充"anonymous" | **标记 user_anonymous**     |
| **like_count** | 原始赞数       | 预相似内容知分平均          | 无法补充            | **标记 like_count_unknown** |

**准确性评估指标**： post_quality = ∑(field_weight × field_confidence) / ∑field_weight； >= 80%: 可直接使用， >= 60%: 使用但标记， >= 40%: 需审核， < 40%: 无效

**存储建议**:

- 表名：`social_platform_post`
- 主键：`post_id`
- 索引：`(user_id, post_time, like_count)`
- 全文索引：`content`
- 分区：按 platform + post_date
